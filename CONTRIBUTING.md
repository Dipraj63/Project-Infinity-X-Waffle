# Contributing to Project Infinity-X for OnePlus 12

Thanks for your interest in improving this project!

Contributions involving build fixes, device-tree improvements, kernel compatibility, and documentation are welcome.

## Before contributing

- Read the README.md and build instructions.
- Check existing issues and pull requests before starting duplicate work.
- Use the correct Android 17 / Project Infinity-X branch.
- Keep changes focused and explain why they are needed.

## Device tree development

The device trees are maintained in these repositories:

- https://github.com/Dipraj63/android_device_oneplus_waffle
- https://github.com/Dipraj63/android_device_oneplus_sm8650-common

Submit device-tree changes to the appropriate repository rather than copying their source files into this build-setup repository.

## Build and testing

Before submitting a build-related change:

1. Sync the required source repositories.
2. Run the appropriate build commands.
3. Check build logs for errors.
4. Test on actual OnePlus 12 hardware when possible.
5. Clearly state whether the change was compile-tested or device-tested.

Do not claim a feature works unless it has been tested.

## Pull requests

When opening a pull request, include:

- A clear description of the change.
- The reason the change is necessary.
- Relevant commit references.
- Build or testing results.
- Known limitations or regressions.

Keep pull requests small and focused where possible.

## Licensing

By contributing, you agree that your contributions are provided under the applicable license of the repository or source file being modified.

Do not submit proprietary files, leaked firmware, copyrighted material, or code without permission to redistribute it.

Third-party repositories retain their own licenses.

## Respectful collaboration

Be respectful and constructive when discussing bugs, patches, and development decisions.

Thank you for helping improve OnePlus 12 development!
